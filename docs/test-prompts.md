# Тестовые запросы для истории tickturn

Отправляйте по одному в этот чат. Каждый покрывает свой случай в панели `/time`.

1. **Короткий ответ (секунды)**
   `Сколько будет 17 * 23?`

2. **Ответ средней длины (~30–60 с)**
   `Объясни в пяти предложениях, как работает хук turn.complete в этом моде`

3. **Длинный текст запроса — проверка обрезки до 25 символов с «…»**
   `Прочитай hooks/register.tsx и перечисли все обработчики событий, которые регистрирует мод, с одной строкой описания для каждого`

4. **Прерванный ход — пометка «(прервано)»**
   `Запусти claude plugin validate . и подробно разбери каждую строку вывода`
   Через 5–10 секунд нажмите Esc — в истории появится `(прервано)`.

5. **Пустой текст — пометка «(без текста)»**
   Отправьте сообщение из одних пробелов или только с вложением.

6. **Долгий ход (минуты) — проверка формата m:ss и живого отсчёта**
   `Сделай ревью register.tsx: ошибки, краевые случаи, предложения по упрощению`

7. **Быстрый повтор — несколько записей подряд**
   `Привет`, затем `Как дела?`, затем `Спасибо`

8. **Сброс истории**
   `/clear` — панель должна показать «Запросов ещё не было.», полоса исчезнуть.

После пунктов 1–7 откройте панель командой `/time` или кнопкой **История**:
ожидается 9 записей, у 4-й суффикс `(прервано)`, у 3-й и 6-й обрезанный текст, итог = сумма.
